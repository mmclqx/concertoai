## 二、实现（`scripts/smoke-install.mjs` 就地重写，331 行）

- 模式：默认本地 tarball（`npm pack --pack-destination <tmp>`，仓库零污染）/ `--registry <ver>`（装线上包）/ `--keep`；
- 退出码：全绿 0、任一红 1、中断 1（便于接 CI）；`npm run smoke:global` 为便捷入口；

- 6 条断言：⓪ 探针通电（两垫片存在且非空 + 安装包 version = 期望版本）① `concertoai --version` ② `ccai --version` ③ `chat --help` 含 `--auto-low` 且**不含** `--bogus` ④a 拼错有建议 ④b 无候选不瞎猜；
- 期望版本**不硬编码**：本地取 `package.json.version`、registry 取请求版本（v5.1.0 那次的假红就是硬编码）。

## 三、取证陷阱：本轮我自己踩了三次，全部记进脚本注释

| # | 陷阱 | 表现 |
|---|---|---|
| 1 | `& echo %errorlevel%` | cmd **解析整行时**展开 ⇒ 拿到的是上一条命令的残留值（第一次量出 `EXIT=3`，因为路径变量还没赋值） |
| 2 | PowerShell `$LASTEXITCODE` | 命令没真跑（如 `try{}` 里抛错）时是**残留值**，不代表本次结果 |
| 3 | Node `spawnSync(cmd, ['/c', '"<path>" args'])` | Node 把 `"` 转义成 `\"`，cmd 不认 ⇒ `'\"C:\...\concertoai.cmd\"' 不是内部或外部命令`。修法：`windowsVerbatimArguments: true` + `call "<path>" args` |

⇒ 脚本改为**完全不用 shell**：所有子进程 `spawnSync` 直取 `status`；唯一例外是 Windows 执行 `.cmd` 垫片（必须经 `cmd /d /s /c`）。最终所有测量都用 `cmd /v:on` + `!errorlevel!` + 字面路径。
