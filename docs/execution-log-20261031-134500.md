## 四、验收判据（行为层，不接受「grep 命中归零」当证据）

2. **闸门有牙（不花真钱自证）**：把阈值注入成 `¥0.0001` 跑 mock 场景 → 第一个场景后必须打印「🛑 超阈值」并停止后续场景；反向对照：阈值注入 `¥999` → 全部跑完。此自证必须能在 `npm test` 里复现（`scripts/lib/cost-gate.mjs` 纯函数用例）。
3. **不可度量时 fail-closed**：故意让成本行缺失（例如老版本 dist / 注入 client）→ 脚本不得继续跑真钱场景，必须打印「读不到本次消耗，停止」并以超预算口径退出。
4. **零串账**：`review --fix`（同一 client 内两段）成本行覆盖两段；`commit` 单独跑只报自己那一次。
5. **全量回归**：`npm run verify` 全绿，用例数 = 基线 + 新增（逐条报数）；`npm run verify` 之外不引入新的真钱路径。
6. **文档一致**：脚本头注释里「按差额记账」这类**过期说法**必须同步改掉（AGENTS 提交前自查第 1 条：常量/口径改动要搜全引用）。
