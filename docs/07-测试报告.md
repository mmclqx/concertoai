## 6. 测试环境与命令

| 命令 | 作用 |
| --- | --- |
| `npm test` | 全量测试（`vitest run`，22 文件 218 用例，约 3s） |
| `npm run test:watch` | 监听模式 |
| `npm run lint` | Biome 检查 `src`、`tests` |
| `npm run lint:fix` | Biome 自动修复 |
| `npm run typecheck` | `tsc --noEmit` |
| `npm run verify` | `build` + `lint` + `typecheck` + `test --silent`（CI 统一入口） |
| `npm run dev` | 开发运行（默认进 chat 模式，需真实 TTY） |
| `npm run dev -- run "任务"` | 非交互执行（真实 API） |

- **环境要求**：Node ≥ 22（`package.json` engines）、npm；无网络依赖（全部测试走本地 mock / 临时目录 / 真实子进程）。
- **CI**：[`.github/workflows/ci.yml`](.github/workflows/ci.yml) —— `ubuntu-latest` + `windows-latest` × Node 22，`npm ci` 后 `npm run verify`；另有 [`publish.yml`](.github/workflows/publish.yml)（Trusted Publishing npm 发布）。
- **vitest 配置要点**（[`vitest.config.ts`](vitest.config.ts)）：include `tests/**/*.test.{ts,tsx}`（必须含 `tsx`，否则 UI 测试被静默跳过）；environment `node`；未配置 `testTimeout` / `retry` / coverage（默认值；coverage 在 `@lumende/cli` 中配置，Lumen 暂未启用）。
- **测试模式**：所有测试走本地构造——`client.test.ts` 手工拼接 SSE 字节流逐字节喂入 `readSseEvents`；`loop.test.ts` 用 `FakeModel` 脚本驱动全链路（含审批拒绝、并行调度、修复管线）；工具测试用 `mkdtempSync` 临时目录；UI 测试用 `ink-testing-library` `render` + `stdin.write` 模拟按键。

## 7. 已知覆盖缺口

1. **无真实 DeepSeek API 集成测试**：模型客户端全部走本地 mock（构造 SSE 帧 + `fetch` mock），`api.deepseek.com` 的真实网络通路、限流、prompt-cache 命中行为仅靠手动验证（M-02）。
2. **CLI 入口覆盖薄弱**：`cli/chat.test.ts` 仅 2 个用例覆盖 `printSessionList`；`cli/index.ts`（commander 路由）、`chat.tsx`（TTY 检查与装配）、`run.ts`（非交互执行）、`plan.ts`（plan CLI）均无独立测试文件——其核心逻辑分别通过 `loop.test.ts` 和 `app.test.tsx` 间接覆盖。
3. **TUI 端到端薄弱**：真实终端渲染、IME 中文输入、窗口 resize、复制粘贴停留在组件级测试（`ink-testing-library`），完整人工路径依赖手动回归（M-01~M-12）。
4. **覆盖率未启用**：`vitest.config.ts` 未配置 `coverage` provider，无法量化行/分支覆盖率。建议后续添加 `@vitest/coverage-v8`。
5. **CI 矩阵有限**：`ubuntu-latest` + `windows-latest`，缺 macOS。实际开发环境为 Windows，跨平台验证已覆盖 Linux。
6. **无变异测试 / 压力测试**：无 Stryker 配置，无并发压力 / 内存泄漏测试。
7. **`shell.test.ts` 进程树杀灭**：Windows 下 `child.kill()` 只杀 cmd.exe 壳，残留子进程可能锁目录（EBUSY）——测试中以重试 `rmSync` 规避，但未验证 `taskkill /T /F` 的实际行为（见 [ARCHITECTURE.md 踩坑记录 #5](../02-架构设计/ARCHITECTURE.md)）。
