## 7. 已知覆盖缺口

1. **无真实 DeepSeek API 集成测试**：全仓库网络路径均为本地 mock / 伪造（`client-v4` 用构造 SSE 帧；[bundle-smoke.test.ts:82](tests/bundle-smoke.test.ts:82) 将 `DEEPSEEK_BASE_URL` 指向 `127.0.0.1:1` fail-fast，未触达 `api.deepseek.com`）。真实模型输出兼容性、限流、网络抖动、prompt-cache 命中行为只能靠 M-02 类手动验证。
2. **桌面端不覆盖**：desktop 源码已移至 https://github.com/Yapie0/carboncode_app，相关测试被 vitest 显式排除，本仓库无桌面 shell 测试。
3. **TUI 端到端薄弱**：真实终端渲染、IME 中文输入、Shift+Enter、鼠标、窗口 resize、复制粘贴主要停留在组件级测试，完整人工路径依赖手动回归。
4. **CI 矩阵缺 macOS**：仅 `ubuntu-latest` + `windows-latest`。
5. **覆盖率整体 71.13% lines / 79.61% branches**：dashboard 前端、QQ 通道、server/api、部分 CLI 启动分支未被完全触达；另有 8 个用例显式跳过。
6. **变异测试未入 CI 门槛**：Stryker 配置存在但 `test:mutation` 不在 `verify` / CI 流程内。
7. **TASKS.md 缺失**：手动测试用例无版本化来源，建议补建该文件并逐步把高频手动用例（M-04~M-07）自动化。
