# V3.2-M1 / T1.2 spawn 命令适配审计清单

> 审计日期：2026-08-11
> 审计范围：全项目 `spawn(` 调用点（node:child_process）
> 审计标准（AGENTS.md 跨平台规范）：Windows 下 spawn `.cmd`/`.bat` 必须 `shell: true`（或显式 `cmd.exe /c`）；`.exe` 可 `shell: false`；命令名应先经 `getPlatformAdapter` 平台适配。
> 结论：**5 处调用点全部合规，无遗漏 shell:false 直跑 .cmd/.bat。**

## 规则要点（固化）

1. 新增 spawn 调用点前先回答：命令是 `.cmd`/`.bat`（→ shell:true）还是 `.exe`/二进制（→ 可 shell:false）？
2. `.cmd` 场景优先复用 `getPlatformAdapter().adaptCommand()` 做命令名平台转换（npx → npx.cmd）；
3. 禁止给已带 `.cmd` 的命令再拼 `.cmd`（`npm.cmd.cmd` → ENOENT，v3.1.1 回归测试兜底）；
4. taskkill 杀进程树仅用于 Windows（POSIX 用进程组 `kill(-pid, SIGKILL)`）。
