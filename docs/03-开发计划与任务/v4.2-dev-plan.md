## 一、设计哲学与定位

ConcertoAI = **终端 AI 开发平台 + 守护代码**。v4.1.1 已把「平台深度」做足（工作流 / autoFix / 多 Provider / 插件市场 / self-heal / LSP / 多项目隔离）。

v4.2 的战略目标：**补齐「上手体验」短板，同时把「模型智能」升级到新价格时代**——向 Carbon Code 学极简上手，但保持平台定位。

用户画像验证：用户会从 Carbon Code（极简）入门，在需要「维护不是自己写的代码」时来用 ConcertoAI（深度）。因此 v4.2 的每一次体验改进都服务这个转化漏斗。

|------|------|----------------|

## 三、原则

1. **不破坏平台深度**：学习 Carbon 的「上手」，不砍 ConcertoAI 的「深度」；新增命令与现有体系风格一致（commander + zod + i18n + 中文优先）
2. **安全优先不妥协**：update 自动升级需显式确认；auto 模型升级需成本上限/审批（无 yolo 模式）
3. **价格数据准确性**：DeepSeek 新价格表必须按「高峰/空闲双价格」建模，状态条成本按当前时段真实展示（不误导）
4. **npx 兼容**：所有新命令在 `npx @concertoai/cli` 场景下也要可用（update 在 npx 场景应提示用全局安装）
5. **可测试性**：每个任务含测试用例；新增命令覆盖「首次运行 / 失败恢复 / 用户退出」三边缘路径（AGENTS 教训）

| 任务 | 用户故事 | 验收标准 |

**DeepSeek 新价格表（2026-08 官方，元/百万 tokens）**：

| 模型 | 缓存命中（空闲/高峰） | 缓存未命中（空闲/高峰） | 输出（空闲/高峰） | 并发 |
|------|------|------|------|------|
| deepseek-v4-flash | 0.05 / 0.10 | 1.5 / 3.0 | 4.5 / 9.0 | 2500 |
| deepseek-v4-pro | 0.15 / 0.30 | 4.5 / 9.0 | 13.5 / 27.0 | 500 |

（当前 models.ts 缓存命中价 0.02/0.025 低于新表空闲价——必须修正，否则成本显示失真。）

**官方高峰时段查询途径（T7 前置，专家补充）**：

| 途径 | 说明 |
|------|------|
| ① DeepSeek 官方文档 | platform.deepseek.com 的 Pricing 页面（通常含「高峰时段」说明） |
| ② API 响应头 | 实际调用时检查响应 `X-RateLimit-*` 或时段相关字段 |
| ③ 官方公告/博客 | 涨价通知中通常说明时段定义（api-docs.deepseek.com 公告） |
| ④ 社区验证 | V2EX / Reddit / HN 开发者实测（交叉验证官方说法） |

查询结果必须**写入 ADR/文档并标注来源 URL**（验收⑦），避免以后时段变更无据可查。

| # | 风险 | 等级 | 缓解 |
|---|------|------|------|

| R4 | init 生成内容质量（模板套话） | 中 | 基于真实文件分析（依赖/脚本/入口/目录），生成内容逐段引用真实证据；手工实测 3 种项目 |

## 八、决策点（已确认 2026-08-17 专家评审）

1. **T6 auto 范围**：✅ **保守方案**（手动 `/model auto` 切换 + 升级前成本提示审批；不做无监督自动升级——违反成本透明 + fail-closed 基线；激进方案留 v4.3/v5.0 待真实用户反馈）
2. **T7 价格展示**：✅ **当前时段真实价格**（用户看到 = 实际要付的钱；高峰显示高峰价即「成本对比」深化）
3. **优先级**：✅ **A 组先行**（npx/update/ccai/THIRD_PARTY 是发布门槛——新用户进不来；T5-T7 是体验增强可后置）
4. **v4.2 范围**：✅ **全含 A+B+C**（8.25h 可控；若时间紧张先发 A 组不影响用户价值）

**专家补充采纳清单**（已并入任务表）：① T5 升 P1（差异化杀手锏——生成「守护指南」非仅项目描述）② T7 先查官方高峰时段并对齐 peak-time.ts ③ T1 必测 npx 缺 Key 中文引导 ④ T4 tiktoken o200k_base 特殊声明 + cli-highlight highlight.js 注明 ⑤ T3 bin 双符号链接 + README 声明等价
