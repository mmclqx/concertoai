- `tests/e2e/npx.test.ts`（新增）

**实现要点**（**分两阶段，用户提醒**）：
- **阶段一（现在，改代码前）**：用**已发布的 v4.1.1** 实测 `npx @concertoai/cli --version` / `--help`——验证 npx 零安装能不能跑（发布门前置）
- **阶段二（T1 代码改完后）**：本地 `npm pack` → `npx <本地 tgz>` 实测缺 Key 引导（验证新代码，不经 npm registry）

**验收标准**：

**实现要点**：
- 分析：package.json（name/scripts/dependencies+devDependencies 数量与主要框架）、入口文件（main/bin/src 探测）、目录结构（顶层条目）、CI/配置存在性（.github/workflows / tsconfig / biome.json）、TODO/FIXME 扫描（计数 + 位置）
