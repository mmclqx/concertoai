## 执行规范

1. **开始任务前**：阅读该任务完整定义，确认依赖任务已完成
2. **执行任务**：按"验收标准"逐项实现
3. **任务完成后**：执行 `npm run verify` 确保全绿，然后更新 TASKS.md 看板
4. **提交代码**：`git add . && git commit -m "T1.x: 任务名称"`
5. **生成总结**：按以下格式输出总结
