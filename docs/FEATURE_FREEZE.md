# 功能冻结声明（v5.0）

> 建立日期：2026-10-29（T20 落文档，T23.2 补齐）
> 适用版本：v5.0.x
> 口径来源：`docs/03-开发计划与任务/v5.0-dev-tasks.md` §T20 功能冻结落文档

## 一句话

**v5.0 只做体验改进，不开新功能面。** 冻结的是「功能增量」，不是 bug 修复、不是文档、不是测试。

## 一、冻结声明

v5.0 的定位是「从黑盒引擎到透明驾驶舱」——全部预算花在**让人看得懂、敢用**上（审批风险教学卡、场景提示、4 个动词、体验度量），而不是横向铺功能。

因此本版本约定：**新增用户可见功能面 = 违反冻结**。判断标准见第四节。

## 二、冻结范围

| 冻结的是什么 | 不冻结的是什么 |
|---|---|
| 用户可见的**新命令 / 新子命令 / 新斜杠命令** | ✅ bug 修复（任何模块） |
| 现有命令的**新能力面**（新增参数带来新行为） | ✅ 文档（含本文件） |
| **新模块目录**（`src/` 下新增一级功能目录） | ✅ 测试（只增不砍，见第四节） |
| 新 Provider / 新插件类型 / 新工作流模板 | ✅ 重构（不改变对外行为） |
| 新配置项（除非为降级/关闭既有功能所必需） | ✅ 性能优化 |

## 四、测试策略（T20 明确写入）

- **既有用例全保留**；当前基线 **155 文件 / 2209 用例**（2026-10-29 实测，T20 立项时基线 1404 用例，此后只增不减）
- **仅允许删除「冻结功能的深层边界用例」** —— 即那些为防止已停止演进的功能继续扩展而存在的用例
- **边缘路径用例一个不动**（AGENTS「测试要求·边缘路径强制覆盖」的四类：首次运行 / 失败恢复 / 主动退出 / 超长截断）
- 冻结功能的 bug 修复**必须补回归用例**，不能只改代码

## 五、判定方法（怎么机械发现「有人加了功能」）

三条可执行判据，任一命中即需人工确认是否属冻结违规：

1. **命令数**：`concertoai --help --all` 的命令条数比上一版多 → 新增了命令
2. **目录**：`src/` 下出现新的**一级功能目录**（非 `utils/`、`store/` 这类基础设施）→ 新增了模块
3. **冻结层文件数**：`src/market/` `src/plugin/` `src/agents/` `src/lsp/` 的文件数增加 → 冻结层在扩写

> **2026-11-07 更新：三条判据均已由代码守护**，见 `tests/cli/freeze.test.ts`（26 用例，`npm run verify` 自动跑）：
> ① 命令数 → 真跑 `concertoai --help --all` 解析 `Commands:` 段，与本文件 §五 基线逐条比对；
> ② `src/` 一级目录 → 23 个精确集合相等（禁前缀匹配，`agent` / `agents` 并存）；
> ③ 冻结层文件数 → 4 个目录的**文件清单**与台账 6 / 7 / 8 / 5 双向精确相等（不止数个数）。
> 护栏配 7 条反向自证（N1–N6 / N8，外加正例 N7「真实仓库必须零差异」）+ 7 个变异探针（M1–M7），
> 每个探针都实测过「改坏必红（且红在指定用例）→ 改回必绿」。
>
> **两处维护义务（牙就在这里）**：
> - 冻结层的**合法**变更必须**同一提交**内更新 `tests/cli/freeze.test.ts` 的基线常量与本文件 §三 台账，提交信息写明理由；解冻还须按 §七 新建 ADR。
> - 护栏**不统计以 `.` 开头的条目**（`src/` 下的一级目录与冻结层内部均不统计）。原因：LSP 修复副本（`src/lsp/diagnostics.ts` 的 biome `includes` 约束）与它的集成用例都会在 `src/` 下建 `.` 开头临时目录，并行跑全量时会被误报成「新增模块」——**假红会让护栏当天失信**。代价：隐藏目录下的垃圾本护栏看不见，由 `git status --ignored` 人工清理（`.gitignore` 已挡 `src/.lsp-fix-itest-*/`、`src/.concertoai-lsp-fix-*/`）。

## 七、解冻条件

满足任一条即可在下个 minor 解冻对应层，且**必须新建 ADR 记录理由**：

1. 下游有明确用户需求 + 维护成本已被证明可接受
2. 该层出现必须扩展才能修的安全缺陷
3. 版本策略调整（如 v6.0 重新立项）

**解冻不等于删除本文件**——本文件应持续记录每一层的状态变迁。
