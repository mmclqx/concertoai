# [2026-08-09] v3.0 发布时版本号未同步（package.json 与 VERSION 常量仍为 2.1.0）

## 问题描述
- 现象：v3.0 代码全部就绪，但 `package.json` 与 `src/version.ts` 的 `VERSION` 仍为 `'2.1.0'`；`lumen --version` 输出错误版本号，发布门检查被审核报告标记为 🔴 I1 必须修复
- 环境：Windows

## 根因分析
- 直接原因：版本号只在「npm version 流程」时同步，而 v3.0 全量开发期间未执行过 `npm version`，两处版本号停留在 2.1.0
- 深层原因：版本号存在 `package.json` 与 `src/version.ts` 两个事实来源（v2.1 性能优化把 VERSION 从 barrel 迁到独立模块），缺少「发布前核对版本号一致性」的检查项；且 `scripts/sync-version.mjs` 钩子仍指向 `src/index.ts`（VERSION 已迁走），`npm version` 时钩子会同步失败

## 解决方案
- 修复方式：手动将 `package.json`、`package-lock.json`（顶部两处）、`src/version.ts`、`tests/smoke.test.ts` 同步为 `3.0.0`；并修复 `scripts/sync-version.mjs` 指向 `src/version.ts`
- 涉及文件：`package.json`、`package-lock.json`、`src/version.ts`、`tests/smoke.test.ts`、`scripts/sync-version.mjs`

## 经验教训
- 如何避免同类问题：发布门检查清单增加「版本号一致性核对（package.json ↔ src/version.ts ↔ smoke 测试）」；每次发版前先跑 `npm run verify` 中的 smoke 测试（断言 VERSION）
- 是否需要更新规范：✅
- 规范更新位置：`AGENTS.md`（发布门检查清单）
