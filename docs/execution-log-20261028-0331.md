## S3. PTY 清理兜底修复（03:36-03:37）

`scripts/pty-drive-t13.mjs` 重构：

| # | 改动 | 要点 |
|---|---|---|
| 1 | `LIVE_TERMS = new Set()` | `runTui` 里登记存活 PTY |
| 2 | `killTermTree(term)` | 先 `term.kill()`；Windows 下**先探活**（`process.kill(pid, 0)`）再 `taskkill /pid <pid> /T /F`，避免误伤复用的 pid（对齐 `src/agents/qa.ts` 的 killTree） |
| 3 | `cleanup()` | `cleaned` flag 幂等；先杀 PTY 再 `rmSync`（`maxRetries: 5` / `retryDelay: 100` 对付 Windows EBUSY）；**失败打印残留路径**，禁止静默 |
| 4 | 进程级兜底 | `process.on('exit')` + `SIGINT`/`SIGTERM`/`SIGHUP` + `uncaughtException`/`unhandledRejection` |
| 5 | 单出口 | `run()` 包 `try { ... return code } finally { cleanup() }`，删掉 2 处裸 `rmSync` + 2 处 `process.exit`，改 `process.exitCode` |
| 6 | **顺序自纠** | 第一版把 `LIVE_TERMS.delete(term)` 放在 `term.kill()` **之前**（= 杀之前先放弃兜底）→ 改为 `detach()` 只清定时器，term 留给 cleanup；正常收尾也改走 `killTermTree()` |
