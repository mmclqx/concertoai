## 六、诚实记录：探针自身的 7 处缺陷（不是产品的问题）

1. 首轮**误用真 Key**：`schemaVersion: 1` 触发 v3→v4 迁移丢弃手写的 `baseUrl`/`apiKey` + 直通 `{...process.env}` 让真 Key 顶掉 mock。
2. 「（真实）」判据错（那是 usage 来源标记，本地 mock 也有）。
3. 断言对象错（TUI 的 `run_command` 不显示工具输出）。
4. 时序错（1200ms 敲斜杠命令被未挂载的 stdin 吞掉）→ 加就绪门。
5. 断言与设计相反（`/metrics on` 是会话级，不写配置）。
6. 场景 6 fixture 没造「暂存区空」这一失败路径。
7. 场景 6 被测子进程缺 git 身份（`GIT_IDENTITY` 只给了脚本自己的 `git()`）。
