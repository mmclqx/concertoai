## 二、性能基准对比（T8.2a）

> 方法：同一机器（Windows x64 / Node v22）分别测 v3.x 基线（全局 npm 包 v3.2.0，v3.4 无独立全局包，作为 v3.x 近似）与当前 v4.0 开发构建（dist）。冷启动 = `--version` 命令从 spawn 到输出的墙钟时间，测 3 次取中位数。

| 指标 | v3.x 基线（v3.2.0） | v4.0（当前构建） | 结论 |
|------|---------------------|------------------|------|
| 冷启动 `--version` | 164 ms | 139 ms | ✅ 未退化（略快 ~15%，启动期缓存 ADR-029 生效） |
| dist 体积 | 1342 KB | 2091 KB | ⚠️ +56%（功能面 M1-M7 大幅扩展，冷启动未随体积退化） |
| build 耗时（esbuild） | ~71 ms（v3.1 实测） | 94 ms | ✅ 同量级（esbuild 链路稳定） |

**结论**：v4.0 功能面从「单体工具」扩展为「插件化平台」（+750KB 产物），但冷启动未退化（139ms vs 164ms），首响应由流式渲染主导（与版本无关），内存占用随进程常驻（插件进程内加载，无额外进程开销）。
