## 二、doneProof 刷新（用脚本，不手改 JSON）

`instruction-state update --set-status done` 的契约是**终态重跑全部判据、一律不复用历史 evidence**，并自动写 `doneProof`（head + 三档 + 每条判据的 exitCode 与 digest）。手改 JSON 等于伪造证据，所以走脚本：

```
node scripts/instruction-state.mjs update --set-status done --reason "v5.1 全部门禁通过：12 条发布门（含第 12 条降级说明行 fcc60c9）+ 7 条判据复验 exit 0 + 双环境 177/2665 全绿；复验覆盖 bump 5.1.0 与 smoke 版本断言修复两个提交"
```
