## 八、遗留与观察

1. **P1 那条判断目前无测试能钉住**（删掉它 18/18 仍绿）。取舍已写在用例 #4 注释里：保留它（省 50-70ms），但不假装它被护栏覆盖。若将来有人问「这条删了会怎样」，答案是「慢一点，行为不变」。
2. **hook 里的 locale 规则是复刻**（提交时 `dist/` 可能未构建），漂移由 20 条等价性表兜住；`src/i18n` 改规则时该表会红，届时**同时改 hook 与用例**。
3. **`--no-verify` 用例依赖 `git` 版本行为**（实测 2.45.1.windows.1）。若某个 git 版本开始让 `--no-verify` 也绕过 `prepare-commit-msg`，该用例会红——那正是我们希望被告知的（提醒机制失效）。
4. **性能用例阈值 300ms 是宽松值**（实测净增 34~72ms 抖动）；它只拦「有人往 hook 里塞 dedup/verify」这种量级的改动，不拦机器抖动。
