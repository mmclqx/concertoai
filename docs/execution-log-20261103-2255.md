### 4.3 结构性连带（需用户知晓）

- **`excessArguments` 口径修正会改变现有输出形状**：`bogus-xyz` 从「Expected 0 arguments」变成「没有这个命令 `bogus-xyz`」。若有外部脚本 grep 旧串会失效——本项目为 CLI 产品，**无外部契约约束**，但要在 CHANGELOG 写明。
- **`exitOverride` 后必须自己设 `process.exitCode`**：`exitOverride` 会把 `process.exit` 换成抛 `CommanderError`，若不接管，`--help`（exitCode 0）与报错（exitCode 1）都可能变成「静默成功」。这条必须有事例兜住（`--version` 仍 exit 0 / 报错仍 exit 1）。
- **`tests/cli/help.test.ts` 现有断言有两处会被 C2 触碰**：L175-176 断 `firstScreen` 不含 `Commands:`、`fullHelp` 含 `Commands:`（这两条是**英文标题**）；L315 断言 `Usage: concertoai [options] [command] ConcertoAI — a personal super CLI`。若 ⑦ 真把 `Usage:`/`Commands:` 本地化，这两处必须**同步改成字典取值**（不是改成硬编码中文，否则护栏变成第二份文案）。
