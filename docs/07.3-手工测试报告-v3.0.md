**参考脚本**（`scripts/manual-orchestrator.ts`）：

```typescript
import { DeepSeekClient } from '../src/model/client';
import {
  InMemoryAgentRegistry,
  Orchestrator,
  ArchitectAgent,
  CoderAgent,
  TeamReviewerAgent,
  QaAgent,
} from '../src/agents';

async function main() {
  const client = new DeepSeekClient({ apiKey: process.env.DEEPSEEK_API_KEY! });
  const registry = new InMemoryAgentRegistry();
  const ctx = { sessionId: 'manual', taskId: 'root', parentTaskId: undefined, dependencies: [], artifacts: [] };
  const opts = { client, model: 'deepseek-v4-flash' };
  // 注册 4 个内置 Agent（权限声明 + 实现；execute 需真实模型）
  registry.register({ name: 'architect', version: '1.0.0', interfaces: { input: {} as never, output: {} as never, version: '1.0.0' }, permissions: [] }, new ArchitectAgent(opts));
  registry.register({ name: 'coder', version: '1.0.0', interfaces: { input: {} as never, output: {} as never, version: '1.0.0' }, permissions: [] }, new CoderAgent(opts));
  registry.register({ name: 'reviewer', version: '1.0.0', interfaces: { input: {} as never, output: {} as never, version: '1.0.0' }, permissions: [] }, new TeamReviewerAgent(opts));
  registry.register({ name: 'qa', version: '1.0.0', interfaces: { input: {} as never, output: {} as never, version: '1.0.0' }, permissions: [] }, new QaAgent(opts));
  const orch = new Orchestrator({ client, model: 'deepseek-v4-flash', registry, onPlan: async () => true });
  const result = await orch.run('实现一个 TODO 应用（含认证）', ctx as never);
  console.log(JSON.stringify(result, null, 2));
}
void main();
```

> ⚠️ 若 4 个 Agent 真实执行成本高，可只验证拆解：`decomposeRequirement(client, model, req)` 后打印任务清单。

### 1.4 多文件事务回滚（M3 / T3.6）

> 交互入口：`concertoai snapshot` 命令 + SnapshotManager 库 API。本组验证快照的创建/回滚/清理与外部修改保护。

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 准备临时目录，创建 `src/a.ts`（内容 X）、`src/b.ts`（内容 Y） | 目录就绪 |
| 2 | 临时脚本：`new SnapshotManager(tmp).begin('task-demo', ['src/a.ts','src/b.ts','src/new.ts'])` | 创建 `.lumen/snapshots/task-demo/`，含 files.json + 快照文件（new.ts 标记新增） |
| 3 | 修改 a.ts → X'、b.ts → Y'，新建 new.ts，调用 `recordWrite('task-demo', ...)` 登记 | 登记写入 |
| 4 | `rollback('task-demo')` | `ok: true`，a/b 恢复 X/Y，new.ts 被删除；快照目录自动清理 |
| 5 | 重复 2-3，但**手动修改 b.ts 为 Z**（不 recordWrite）后再 rollback | b.ts 判为外部修改：`failed` 非空、`ok: false`、快照保留、b.ts 保持 Z（不静默覆盖） |
| 6 | `concertoai snapshot` | 列出残留快照（如 task-demo） |
| 7 | `concertoai snapshot clean` | 清理全部残留快照，再次 `concertoai snapshot` 显示「无快照」 |

**结果**：☐ 通过 / ☐ 失败 — ______

**参考脚本**（`scripts/manual-snapshot.ts`）：

```typescript
import { mkdtempSync } from 'node:fs';
import { mkdirSync, writeFileSync } from 'node:fs';
import os from 'node:os';
import path from 'node:path';
import { SnapshotManager } from '../src/orchestrator';

const tmp = mkdtempSync(path.join(os.tmpdir(), 'concertoai-tx-'));
mkdirSync(path.join(tmp, 'src'), { recursive: true });
writeFileSync(path.join(tmp, 'src/a.ts'), 'X', 'utf8');
writeFileSync(path.join(tmp, 'src/b.ts'), 'Y', 'utf8');
const tx = new SnapshotManager(tmp);
await tx.begin('task-demo', ['src/a.ts', 'src/b.ts', 'src/new.ts']);
writeFileSync(path.join(tmp, 'src/a.ts'), "X'", 'utf8');
writeFileSync(path.join(tmp, 'src/b.ts'), "Y'", 'utf8');
writeFileSync(path.join(tmp, 'src/new.ts'), 'NEW', 'utf8');
await tx.recordWrite('task-demo', 'src/a.ts', "X'");
await tx.recordWrite('task-demo', 'src/b.ts', "Y'");
const rb = await tx.rollback('task-demo');
console.log('rollback:', JSON.stringify(rb));
// 期望：restored=[a,b], deleted new.ts, ok=true, 快照已清理
```
