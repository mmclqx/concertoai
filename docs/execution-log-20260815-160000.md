## 完成标准

- workflow run：失败输出先一行摘要（tsc/biome/npm 智能提取）再截断详情，无 20k 淹没
- F 选项：等待手动修复（60s 超时自动放弃回滚），Enter 重试 / a 放弃，非 TTY 安全降级
- 进度刷屏根因消除：executor 不再内部自动重试（maxRetries: 0）；步骤 retry 字段 = 恢复后重试上限（缺省无限，向后兼容）
- precommit 等模板 run 前预检：缺失脚本/未安装依赖/缺配置 → 报告 + Y/N 自动初始化（lint/typecheck 可自动，test 仅提示）
- CLI 错误提示带「💡 下一步」；--help 分组 + 示例 + 新手路径；首次运行欢迎引导
- AGENTS.md 新增「边缘路径强制覆盖」测试规范
- i18n zh/en 全键一致；回归测试补强；npm run verify 全绿；发布 v4.1.0（npm + tag）；工作区归零
