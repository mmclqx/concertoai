# 发布流程（@concertoai/cli）

> 发布前先通读本页；发布是单向操作，版本号一经发布不可覆盖。

## 前置检查

- [ ] `npm run verify` 全绿
- [ ] `npm audit` 无 high/critical（或已评估记录）
- [ ] CHANGELOG.md 的 `[Unreleased]` 条目已整理
- [ ] 模型定价页无变化（若官方调整过，先更新 `src/model/models.ts`）
- [ ] 版本号一致性核对：`package.json` ↔ `src/version.ts` ↔ `tests/smoke.test.ts`
- [ ] 手工测试报告已生成并填写落盘：`docs/07.{版本号}-手工测试报告-v{版本号}.md`（参考 07.1/07.2/07.3 格式，含测试日期 / 环境 / 通过失败项 / 已知问题）
- [ ] 本次版本修复的踩坑记录已归档：`docs/09-踩坑记录/YYYY-MM-DD-问题简述.md`（如有 Bug 修复）
- [ ] npm 令牌有效性验证：`npm whoami` 能返回用户名（401/403 则先 `npm login` 重新生成令牌，见下方「方式 B」说明；教训见 09-踩坑记录/2026-08-11-npm-token-expired.md）

## 版本号（npm version 流程）

```bash
npm version patch   # 或 minor / major
```

该命令自动完成：

1. bump `package.json` 版本号；
2. 运行 `version` 钩子 → `scripts/sync-version.mjs` 同步 `src/index.ts` 的 `VERSION` 常量；
3. 生成 git commit（含上一步的文件改动）与 tag（`v0.1.1`）。

然后**手动**更新 CHANGELOG.md：把 `[Unreleased]` 内容移动到新版本小节并补日期，
再提交一次（`git commit -m "docs: 更新 CHANGELOG"`）。

## 发布（两种方式）

### 方式 A：GitHub Actions + Trusted Publishing（推荐）

1. 推送版本 tag 到 GitHub；
2. npmjs.com 包设置中启用 **Trusted Publishing** 并关联本仓库（一次性配置）；
3. 在 GitHub Actions 手动触发 `Publish` workflow（`.github/workflows/publish.yml`）：
   `npm ci → verify → npm publish --provenance --access public`，OIDC 认证，无需 token。

### 方式 B：本地发布（备用）

```bash
npm login            # 需要 npm 账号，且被授予 @concertoai/cli 发布权限（web 认证，自动写入 ~/.npmrc 新令牌）
npm whoami           # 确认令牌有效（返回用户名即通过；401/403 说明令牌失效，重新 npm login）
npm publish          # prepublishOnly 自动先跑 verify；账户开启 2FA 时按提示输入 OTP
```

> 令牌说明：npm 令牌有有效期（默认 1 年），过期后 `npm publish` 会报 **403 Forbidden / 2FA 验证失败**（详见 09-踩坑记录/2026-08-11-npm-token-expired.md）。令牌接近过期前主动 `npm login` 或 `npm token create` 重新生成；长期方案是切换「方式 A」Trusted Publishing（OIDC 认证，无令牌过期问题）。

## 发布后

- `scripts/smoke-install.mjs` 做安装冒烟：`node scripts/smoke-install.mjs`（npm pack → 干净目录全局安装 → `concertoai --version`）
- 在真实终端验证 `concertoai chat` / `concertoai run "任务"` / `concertoai plan "任务"` 各一条
- 更新 docs/02-架构设计/ARCHITECTURE.md 中与本次发布相关的部分（如已知问题清单）

## CHANGELOG 维护约定

- 未发布变更记入 `[Unreleased]`；发布时移动到对应版本小节；
- 分组：Added / Changed / Fixed / Removed；每条一行、面向用户。
