## 四、本轮自己踩到的三个坑（都记进踩坑记录）

1. **变异探针串味**：第一版脚本只恢复「当前要改的文件」，M1 的改动残留到 M2 上 ⇒ M2 也红 4 条，
   读起来像「M2 不独立」。修法：**每次变异前把全部目标还原**，再只改一个。
2. **辅助断言用了猜的文案**：`--metrics` 用例断言输出含「本地指标」，真实文案是「本地体验指标」⇒ 红。
   这类断言的作用是「证明走到了那段代码」（否则「没写盘」可能只是「开关没生效」），
   **文案必须跑一次真 CLI 取值**，不能凭印象写。
3. **源码护栏要配正例**：`branch.includes('writeConfig(')` 恒 false 也可能是「切片取空了」。
   故先断言「三个函数名在文件里确实存在」+「切片长度 > 20」。
