### 22:06 实测发现 2 个真实质量缺陷（单测未覆盖）

1. **导出聚合行误报鉴权**：`PROJECT_GUIDE` 把 `export const lib = { u, get, canAccess };` 列进「最脆弱的地方」——这不是鉴权逻辑。原 auth 规则里 `\bcanAccess\b` / `\bisAdmin\b` 不限调用形式。改为要求后跟 `(`（`canAccess\s*\(`），并补 `\bbearer\b`。
2. **推荐了尚不存在的命令**（严重，v4.1.1「装好却跑不通」同类）：生成的指南写「`concertoai review <file>` / `concertoai check` / `concertoai commit` / `concertoai fix`」，但**这些 CLI 动词要到 M4（T15-T18）才落地**，用户照做只会看到 unknown command。改为当前真实可用的 `/review`（chat 内斜杠）+ `concertoai self-heal`，并在代码里注释「M4 完成后由 T19 护栏统一改回动词形式」。
