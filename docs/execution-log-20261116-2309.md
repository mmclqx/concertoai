**本轮不动**：补打历史 tag 会改变既有发版记录（且 tag 一旦推送就难收回），属用户裁决范围，见 TASKS 候选登记。

两种结果在脚本里都可能被当成「没问题」，这正是坏尺子的典型形态）。
