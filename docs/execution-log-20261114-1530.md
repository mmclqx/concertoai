### 取证时另发现一个「Windows 假绿」（比 (a)/(b) 之争更重要）

`spawnSync(…, { env: {} })` 在 Windows 上子进程**仍有 11 个变量**（`PATH` / `SYSTEMROOT` / `WINDIR` / `TEMP` / `USERPROFILE` / `HOMEDRIVE` / `HOMEPATH` / `SYSTEMDRIVE` / `USERNAME` / `USERDOMAIN` / `LOGONSERVER`）——libuv 会自动补一组必需变量。
⇒ **「本机把 env 削成空也全绿」不能证明 (b) 可用**：POSIX 的 `spawn` 按给的那份 env 原样传，而本仓库 CI 是 ubuntu / windows / macos 三平台 ⇒ (b) 会本地绿、Linux/macOS 上 hook 找不到 node、提醒段静默、断言「期望中文提醒」的用例整片红。
判据一句话：**「我这台机器上削掉还能跑」不构成证据——能削掉的是 libuv 补的那一组，不是我抄的这一组。**
