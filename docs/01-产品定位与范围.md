# Lumen 产品定位与范围

> 版本：v1.0 · 2026-08-07
> 状态：已定稿

---

## 1. 一句话定位

**Lumen 是一款面向个人开发者的终端编码助手 CLI**——在项目目录里启动，读取代码、提出 diff 方案、征求命令许可、跑验证，并留下可续接的会话记录。

## 2. 目标用户

| 用户类型 | 描述 |
|---------|------|
| **主要用户** | 个人开发者、独立开发者、开源贡献者 |
| **使用场景** | 日常编码辅助、代码重构、项目探索、学习新代码库 |
| **非目标用户** | 团队协作用户、非技术用户、需要图形界面的用户 |

## 3. 核心价值主张

| 价值点 | 说明 |
|--------|------|
| **安全优先** | 编辑与 Shell 命令一律审批，无 yolo 模式，让 AI 辅助而不失控 |
| **中文优先** | 全中文交互与反馈，降低使用门槛 |
| **低成本** | 基于 DeepSeek API，Token 成本远低于同类产品 |
| **本地优先** | 会话记录存储在本地，隐私可控 |

## 4. v1.0 完成定义（Definition of Done）

以下条件全部满足时，即可发布 1.0.0 正式版：

- [ ] 所有 P0 任务完成并验收通过
- [ ] `npm run verify` 全绿（≥160 用例）
- [ ] `npm audit` 无 high/critical 告警
- [ ] 真实 API 端到端冒烟通过（chat/run/resume/审批/中断）
- [ ] Windows 环境冒烟通过（CRLF/中文/TTY）
- [ ] npm 包发布预演成功（`npm pack` + 干净环境安装）
- [ ] 用户文档齐备（README + USER_GUIDE）

## 5. 范围边界

### ✅ v1.0 包含（核心能力）

- CLI 交互（`lumen chat` / `lumen run` / `lumen plan`）
- DeepSeek 流式对话
- 5 个核心工具（读/搜/列/编辑/Shell）
- 审批流（编辑与命令一律审批）
- 会话持久化（JSONL）与 resume
- Ink TUI 交互界面
- 项目规则加载（AGENTS.md / CARBON.md）

### ❌ v1.0 不包含（明确排除）

| 项目 | 原因 | 计划版本 |
|------|------|---------|
| MCP 接入 | 生态面广，需要客户端基建 | v1.1 |
| 子代理 / 技能系统 | 上下文与调度复杂度高 | v1.1 |
| 桌面端 GUI | 与 CLI 定位冲突 | 不做 |
| 多语言（除 EN 外） | 需求不明 | 视反馈而定 |
| 远程会话 / 团队协作 | 超出个人工具定位 | 不做 |

## 6. 成功指标（非强制，用于衡量效果）

- 用户能在一轮对话内完成一个编码任务
- 审批流无用户误操作导致的危险命令执行
- 会话文件可读、可续接
- 从启动到首次回复时间 < 5 秒（含网络延迟）
