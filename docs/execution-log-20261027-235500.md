### 23:53 S1-a 修 biome warning（`noTemplateCurlyInString`）

问题：`'const p = `${base}/../secret`;'` 用单引号写了模板插值字面量，Biome 判「应改成模板字符串」。

- 第一次尝试 `'const p = \${base}/../secret`;'`（字符串内转义 `$`）→ **失败**：`noTemplateCurlyInString` 仍在，且新增 `noUselessEscapeInString`（单引号字符串里 `\$` 是不必要转义，警告从 1 条变 2 条）；
- 最终方案：改用**模板字面量**写，内部 `\`` 与 `\${` 双转义：
  ```ts
  `const p = \`\${base}/../secret\`;`
  ```
  运行时字符串值不变（仍是 `const p = \`${base}/../secret\`;`），语义零变化。

> 教训：非模板字符串里写 `${` 一定被 Biome 抓；要么改成模板字面量（`\${`），要么改用不含 `${` 的等价样例。不要用单引号 + `\$`。

**第一次跑就抓到真问题（RED）**：

- `③ 单规则 10 万字符长行` → **`dependency-change` 1766ms / 预算 20ms（超 88 倍）**，W8 防 ReDoS 红线破了。
- 根因：`patterns` 里 `['"]?\w[\w-]*['"]?\s*:\s*['"][\^~><=]*\d+\.\d+` 的 `\w[\w-]*` 是**无界量词**，
  在长标识符上每个起点贪到行尾再逐字回溯 → O(n²)。
- 修法（`src/core/risk-rules.ts`）：键长收敛为 `{1,40}`，起点改用 `["']` / `\b` 定位（长串内部每点 O(1) 失败）→ 线性：
  - 形态① `["'][\w@/.-]{1,40}["']\s*:\s*["'][\^~><=]*\d+\.\d+`（package.json 真实形态）
  - 形态② `\b[\w-]{1,40}\s*:\s*["'][\^~><=]*\d+\.\d+`（无引号键）
  - 形态③ `"(?:dev)?[dD]ependencies"\s*:`
- 修复后：1766ms → **0.77ms（最慢规则已变成 secret-hardcode）**。

**补测试时又抓到第二个真问题（死模式）**：

- 新加的回归用例 `zod: "~3.23.8"` 不命中 → 查 prefilter 发现旧值 `['": "^', '": "~']` 只覆盖「带引号的键」，
  **形态② 永远过不了粗筛 = 死代码**（与 network-timeout 注释里记的 `maxRetries` 坑同源）。
- 修法：prefilter 收成 `['"dependencies"', '"devDependencies"', ': "']`，覆盖 ①②③ 的字面特征。
- 回归用例（`tests/core/risk-rules.test.ts` 新增 `W8 防 ReDoS` describe）：
