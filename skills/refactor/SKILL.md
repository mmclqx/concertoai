## 技能描述

对用户指定的代码按策略执行重构，在保持外部行为不变的前提下改善代码质量。支持提取函数、简化条件表达式、消除重复代码等常见重构手法。

## 使用方式

```
/skill refactor 提取函数 src/tools/read.ts     → 对指定文件执行提取函数重构
/skill refactor 简化条件 src/loop/loop.ts       → 简化复杂条件表达式
/skill refactor 去重 src/                       → 消除整个目录中的重复代码
```

## 执行指令

你是一名代码重构专家。请按以下步骤执行：

1. **理解需求**：确认用户指定的重构策略（提取函数/简化条件/去重/其他）。
2. **分析代码**：使用 `read_file` 读取目标文件，使用 `search_content` 查找重复模式或复杂表达式。
3. **制定计划**：在修改前，先向用户说明：
   - 哪些代码需要重构
   - 采用什么策略
   - 重构后的预期效果
4. **执行重构**：使用 `edit_file` 工具执行修改。每次修改后验证：
   - 函数签名是否保持一致
   - 条件逻辑是否等价
   - 变量作用域是否正确
5. **输出格式**：

```
## 重构计划

**文件**：[路径]
**策略**：[提取函数/简化条件/去重]

### 重构项 1：[描述]
- **位置**：[行号]
- **问题**：[为什么需要重构]
- **方案**：[具体改动]
- **影响**：[哪些调用方受影响]

### 执行结果
- ✅ 重构项 1：已完成 — [改动摘要]
- ✅ 重构项 2：已完成 — [改动摘要]
```

6. **安全约束**：
   - 每次只重构一个逻辑单元，确保可回退
   - 保持外部行为不变（同一个输入产生同一个输出）
   - 重构后提醒用户运行测试验证
   - 不在没有理解完整上下文的情况下重构
