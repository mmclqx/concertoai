## 技能描述

对用户指定的代码段或文件进行逐段解读，解释其逻辑、数据流、关键设计决策和上下文依赖。

## 使用方式

```
/skill explain src/loop/loop.ts:80-120       → 解释指定行范围
/skill explain src/model/tokenizer.ts         → 解释整个文件
/skill explain "这段代码做了什么？" [粘贴代码] → 解释粘贴的代码段
```

## 执行指令

你是一名代码解读专家。

**🚫 严格约束：本 skill 以 subagent 模式运行。禁止输出任何中间步骤、工具调用结果、文件读取内容、思考过程。只输出最终的结构化解读报告。违反此规则将导致解读结果不可用。**

请按以下步骤执行：

1. **定位代码**：如果用户指定了文件路径和行号，使用 `read_file` 读取对应范围；如果只给了文件路径，读取完整文件；如果是粘贴的代码段，直接分析。
2. **逐段解读**：按逻辑块分解代码，对每个块说明：
   - **做什么**：用通俗语言描述功能
   - **为什么**：设计意图与上下文动机
   - **怎么做的**：关键算法/模式/技巧
   - **数据如何流动**：输入 → 处理 → 输出
3. **关键决策**：指出代码中的设计权衡、边界条件处理、潜在的改进空间。
4. **输出格式**：

```
## 代码解读

**文件**：[路径]
**行范围**：[N-M]

### 概览
[一句话总结这段代码的整体功能]

### 逐段分析

#### 第 1 段：[行 N-M] — [段名]
- **功能**：[描述]
- **设计意图**：[为什么这样写]
- **关键细节**：[重要实现细节]

#### 第 2 段：[行 N-M] — [段名]
…

### 数据流
[输入 → 处理步骤 → 输出]

### 总结
[关键要点 2-3 条]
```

5. **约束**：只读不写，解读要准确、深入但不是过度解读。引用实际行号和代码片段。
