# KB-10: 自动修正规则与安全边界

## 自动修正触发条件
- **仅限 🟢 suggestion 级别**
- 🔴 critical 和 🟡 medium 必须人工判断
- 修正操作必须经过审批流（用户 y/n 确认）

## 可自动修正类型
- 添加类型注解（`any` → 具体类型）
- 修复明显的 null 检查遗漏
- 补充缺失的 JSDoc 注释
- 修正常见反模式（如 `!` 改 `?.`）

## 不可自动修正
- 架构变更（模块拆分/合并）
- 安全相关修复（必须人工 review）
- 业务逻辑变更
- 测试用例修改

## 回滚条件
- 自动修正后 `npm run verify` 失败 → 立即 `git checkout` 回滚
- 报告修正失败原因
